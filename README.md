# MarketBoost – Digital Marketing Agency Website

## 📌 Project Overview
MarketBoost is a responsive digital marketing agency website developed using HTML, CSS, JavaScript, and Bootstrap 5. It showcases the services, portfolio, and contact details of a digital marketing company with a modern and user-friendly interface.

## 🚀 Features
- Responsive design for desktop, tablet, and mobile
- Modern navigation bar
- Hero section with call-to-action
- About Us page
- Services page
- Portfolio section
- Contact page with contact form
- Animated counters
- Scroll animations
- Back-to-top button
- Interactive buttons and hover effects

## 🛠️ Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Font Awesome
